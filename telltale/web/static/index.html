Telltale

Meta AI investigates a vehicle crash. Deterministic code recomputes every claim it makes.

  1. Perceive

    SAM 3.1 tracks every vehicle and timestamps the moment one became a hazard. Muse Spark 1.3 watches the same clip as an independent witness.

    Real dashcam footage

  2. Investigate

    A Muse Wonder agent reads the evidence, uses tools for every number, runs but-for simulations and names the primary cause.

    Generated vehicle logs

  3. Verify

    Plain Python recomputes each claim and, separately, the verdict itself. Unprovable claims are blocked. A disagreement withholds the verdict.

    No model involved
